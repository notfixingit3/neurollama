NeuroWizard

Guided model operations — no Modelfile knowledge required. Each wizard collects only what it needs, previews the Modelfile, then streams the result.

Expand Context
Set a larger num_ctx for any model without editing the Modelfile manually.
Custom Persona
Give a model a custom role or persona via a SYSTEM prompt. Pick a preset or write your own.
Sampling Profile
Apply a Creative, Balanced, Precise, or Fast temperature/sampling preset as a baked-in Modelfile.
Strip Thinking
Create a -nothink variant of a reasoning model that suppresses <think> tokens.
Merge Models
Blend two models with a configurable weight using SLERP or Linear interpolation.
Remove Restrictions
Strip or replace a model's baked-in SYSTEM prompt — removes persona-based refusals and guardrails.
Terse Mode
Bake in a "no fluff" SYSTEM directive — concise, direct answers. Great for CLI and scripting use.
Code Specialist
Lock a model to code-only output for a chosen language. Bakes in low temperature for determinism.
Reproducible Output
Bake in a fixed seed + zero temperature so the same prompt always produces the same response.
Language Lock
Force a model to always respond in a specific language regardless of what language the user writes in.
Format Specialist
Lock output format: Markdown, Plain Text, JSON, Bullet Points, Academic, Socratic, or Devil's Advocate.
Character Creator
Build a named character with personality, speech style, and topics. More detailed than Custom Persona.
RAG-Optimized
Tune a model to answer only from retrieved context — prevents hallucination in RAG pipelines.

Update Ollama

Update Ollama on a registered node via SSH. Linux: downloads the binary directly and restarts the systemd service — the installer is not used, preserving any custom service file. macOS: runs the official install script.

SSH Key Store

Stored keys are AES-256-GCM encrypted at rest. Key material never leaves the server — only the label, username, and fingerprint are returned to the UI. Use this as a fallback when no SSH agent or ~/.ssh/ keys are available (e.g. Docker deployments).
